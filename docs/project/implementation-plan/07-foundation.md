## Provisioning and access decisions

**Documentation checked on 19 November 2026.** The Terraform GCS backend requires an existing bucket and supports locking. Bootstrap that bucket before initializing the environment root. Restrict state readers and enable versioning with a costed retention policy. Separate enduring state, data disks and backups from session-scoped compute. Store secret names in state. Supply runtime secret values through a separate authorized channel. For Standard GKE, enable Workload Identity Federation on the cluster and the GKE metadata server on the node pool.
