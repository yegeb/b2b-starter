# Team workflow

Follow the repository-root `CONTRIBUTING.md` for issues, branch names, commit
messages, pull requests, and human review. Read it before creating or updating
an issue, branch, commit, or pull request. Work on a topic branch and do not
push directly to `main`.

Find or create a focused GitHub issue before starting implementation. Reference
that issue in each related commit and pull request. Do not invent issue numbers.

For delegated work, follow `docs/agent-workflow.md`. Assign each agent a separate
branch and worktree. Read `.agents/skills/asd-ste100/SKILL.md` for technical writing.

Do not add an AI agent or tool as an author, co-author, or contributor in commit
trailers, pull requests, or contributor lists. Use the configured human Git
identity; do not invent or impersonate an identity. Preserve existing human
and upstream attribution. Do not approve your own pull request or bypass the
team's review requirements.
